# Shaikh Inayat — Portfolio

Static portfolio site (HTML + CSS + JS, no build step).

## Run
Open `index.html` in a browser, or serve the folder:
    python -m http.server 8000

## Add your photo
Save your picture as `assets/profile-photo.jpg`. Until then, the "SI" initials show instead.

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel.
