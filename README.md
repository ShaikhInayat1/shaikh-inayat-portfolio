## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ShaikhInayat1/shaikh-inayat-portfolio.git
```

### 2. Navigate to the project

```bash
cd shaikh-inayat-portfolio
```

### 3. Run the website

Open `index.html` directly in your browser, or start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

---

## 🖼️ Add Profile Photo

To add your profile picture:

1. Place the image inside the `assets` folder.
2. Name it:

```text
profile-photo.jpg
```

If no profile photo is available, the portfolio displays the **"SI"** initials instead.
